## 🚀 Highlighted Project: NudgeFin 🧠💸
### *Predictive Behavioral FinTech Ecosystem*

I engineered **NudgeFin**, a full-stack, mobile personal finance platform driven by behavioral economics. Instead of using traditional budget trackers that log expenses reactively, NudgeFin utilizes a predictive Python data pipeline to isolate temporal high-risk windows when a user is prone to impulsive spending, deploying active hardware interventions before the leak happens.

*   **Frontend Architecture:** Multiplatform **React Native (Expo)** mobile client built in **TypeScript**, orchestrating native OS permission flows and mobile hardware notification calendars.
*   **Backend Architecture:** High-speed REST API built with **Python (FastAPI)**, leveraging a strict **Service Layer Pattern** for database isolation and automated OpenAPI (Swagger) documentation.
*   **Data Science Pipeline:** Customized pattern-mining engine developed with **Pandas** and **NumPy** that runs a weighted scoring system (60% frequency / 40% monetary volume) to isolate weekly spending anomalies.
*   **Infrastructure & DevOps:** Structured with a production-grade **PostgreSQL** schema hosted on **Supabase** (optimized with compound indices and active triggers) and fully containerized using **Docker** and **Docker Compose** for seamless, environment-agnostic deployments.
